# Gitosphere Homebrew tap

Homebrew tap for the official Gitosphere CLI.

Install `gsp` on macOS 27 or later with Apple Silicon (arm64):

```sh
brew install --cask gitosphere/tap/gsp
```

Release 0.1.1 has been tested on macOS 27. Earlier macOS versions have not been
validated for this release.

See [gitosphere/gsp](https://github.com/gitosphere/gsp) for supported macOS
versions, checksums, installation, upgrades, rollback, and Agent Skill setup.
This tap references the signed and notarized release DMG; it does not build
the CLI from source.

For bug reports or help using `gsp`, open an issue in
[gitosphere/gsp](https://github.com/gitosphere/gsp/issues).
